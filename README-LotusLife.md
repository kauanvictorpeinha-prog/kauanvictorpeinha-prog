# 🪷 Lotus Life

Prontuário de saúde único — um site desenvolvido para centralizar e organizar informações de saúde do usuário em um só lugar, facilitando o acesso a dados médicos de forma simples e acessível.

Projeto desenvolvido em dupla, como parte dos estudos em desenvolvimento web.

---

## 📋 Descrição

O **Lotus Life** é um protótipo de prontuário de saúde digital, com o objetivo de reunir em um único ambiente as informações de saúde de um paciente — facilitando a consulta e o acompanhamento de dados médicos, sem depender de múltiplos documentos físicos ou sistemas diferentes.

O projeto conta com **6 páginas**, navegáveis entre si, cobrindo as principais telas da aplicação.

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas
- **CSS3** — estilização e layout
- **JavaScript** — interatividade e comportamento das páginas

---

## 🚀 Como rodar o projeto

Este é um projeto front-end simples, sem necessidade de instalação de dependências ou servidor.

1. Clone o repositório:
   ```bash
   git clone https://github.com/kauanvictorpeinha-prog/Lotus-Life.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd Lotus-Life
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador (basta dar dois cliques nele ou arrastar para o navegador).

Pronto! O site já estará funcionando localmente. ✅
